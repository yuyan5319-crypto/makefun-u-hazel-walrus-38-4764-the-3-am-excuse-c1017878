An entry for [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878) on make.fun: one line, in the voice of a hardware wallet that refuses to sign a transaction at 3 AM.

## The line

> My private keys dream at 3 AM. I'm not waking them so you can buy a dog coin.

The excuse is the wallet's own: its private keys are asleep and dreaming, and it will not wake them for a late-night impulse buy. The 3 AM hour is the joke itself — the line makes no sense at 3 PM.

## How to run

Requires Node 22.18+ (no dependencies, standard library only):

```sh
node main.ts
```

This writes the line to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`, falling back to `./output` when run by hand). The output is the line exactly, with no trailing newline.
